## Purpose

This pack turns the existing table-read protocol and episode logs into a usable session handoff. It does not record a read that has not happened.

- `deliverables/current-screenplays/README.txt`
- the five current screenplay PDFs in `deliverables/current-screenplays/pdf/`
- `production/Reality_Fusion_Table_Read_and_Runtime_Protocol_v1.0.md`

## Minimum room roles

- Khru Ba Ice reader;
- NaMo reader;
- younger-character reader (including Mira / Phim where applicable);
- Ethari and institutional-character reader;
- supporting-adult and community-voice reader;
- independent timekeeper / note-taker.

## Session order

1. Confirm the exact source PDF and commit for each episode.
2. Read without stopping to rewrite dialogue.
3. Let the timekeeper capture start, end, silence, archive audio, interface text, correction time, and interruptions.
4. Hold a short debrief only after the episode ends; distinguish performance, pronunciation, pacing, and writing concerns.
5. Complete the episode log before beginning the next episode.
6. Populate the consolidated runtime report only from measured logs.
7. Do not revise a screenplay until findings are recorded and approved.

## Stop / escalate flags

Pause and identify the issue for qualified review if the session reveals uncertainty about medical care, monastic practice, child safeguarding, privacy, consent, synthetic voice, or AI-governance representation. A table read cannot resolve those questions.
