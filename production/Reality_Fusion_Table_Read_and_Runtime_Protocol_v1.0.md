## Purpose

This protocol defines how to test the current Thai screenplay set aloud without converting assumptions into runtime claims. It separates measured performance from later editorial judgment.

## Minimum Participants

Recommended roles:

- one reader for Khru Ba Ice;
- one reader for NaMo;
- one reader for Mira / Phim / younger characters;
- one reader for Ethari and institutional characters;
- one reader for supporting adults and community voices;
- one timekeeper / note-taker who does not perform a role.

A solo read may be used only as a preliminary pass and must not be labelled a full table read.

## Timing Rules

Start the timer at `FADE IN` and stop after the final `FADE OUT` or end card.

Time these elements rather than skipping them:

- silence explicitly written into the scene;
- pauses that create a dramatic turn;
- interface text that must be read or visually understood;
- archival recordings;
- voice-over;
- system countdowns;
- scene transitions that require an audible or visual beat.

Do not artificially slow every action line. The reader should allow only the time needed for the action to register on screen.

## Per-Scene Record

For every scene, record:

| Field | Required entry |
|---|---|
| Episode / Scene | Exact identifier |
| Start time | Timestamp |
| End time | Timestamp |
| Measured duration | Minutes and seconds |
| Dialogue issue | Line or exchange that sounds written rather than spoken |
| Action issue | Action that cannot be clearly visualized or timed |
| Exposition issue | Information repeated after the image already communicates it |
| Voice issue | Character voice becomes generic or interchangeable |
| Performance note | Interruption, silence, breath, overlap, or pronunciation issue |
| Revision priority | Required / Recommended / None |

## Series-Level Checks

The read must test:

- whether EP1 begins clearly without excessive setup;
- whether EP2’s privacy and safeguarding material remains dramatic rather than procedural;
- whether EP3’s farewell accumulates naturally without becoming a sequence of final statements;
- whether EP4’s alien research scenes remain active and distinct;
- whether EP5’s governance scenes retain urgency from survival pressure;
- whether repeated original-recording / synthetic-voice distinctions feel necessary rather than repetitive;
- whether NaMo’s language evolves gradually across episodes;
- whether Mira’s final `ได้ยิน` remains the last spoken response.

## Runtime Reporting

Report three numbers for each episode:

1. raw timed reading;
2. adjusted screen estimate;
3. confidence range.

The adjusted estimate may account for visual action, montage, silence, and interface reading, but every adjustment must be documented.

Required format:

```text
EPISODE:
RAW TABLE READ:
VISUAL / SILENCE ADJUSTMENT:
ADJUSTED ESTIMATE:
CONFIDENCE RANGE:
DATE:
PARTICIPANTS:
SOURCE COMMIT:
```

Do not infer runtime from word count alone.

## Revision Gate

After the read:

- record all findings before editing;
- separate performance problems from writing problems;
- do not rewrite a line solely because one reader stumbled once;
- prioritize repeated failures across multiple readers;
- preserve Canon and revision-history boundaries;
- create a new screenplay revision only after the findings are approved.

## External Review Flags

The table read cannot validate:

- medical or palliative-care procedure;
- Buddhist funeral or monastic practice;
- child-safeguarding policy;
- privacy or consent compliance;
- AI-governance legality;
- alien technology plausibility.

Those remain separate specialist-review tasks.
