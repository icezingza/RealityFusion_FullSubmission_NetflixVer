# Reality Fusion — Script Synopsis v2.0

Status: CURRENT CANON

## Series Synopsis

ครูบาไอซ์ พระภิกษุหนุ่มผู้มีพื้นฐานด้านซอฟต์แวร์ พบว่าคำสอนบนใบลานเก่ากำลังผุพัง เขาจึงสร้าง NaMo ระบบ AI เพื่อช่วยอ่าน แปล และจัดเก็บความรู้จากใบลานกับคลังพระไตรปิฎกดิจิทัล

แต่ NaMo ไม่ได้ผิดพลาดแบบเครื่องจักรที่หยุดทำงาน มันผิดพลาดด้วยคำตอบที่ฟังน่าเชื่อถือเกินหลักฐาน ครูบาจึงเริ่มสอนระบบให้แยกข้อเท็จจริง การตีความ และการคาดเดาออกจากกัน พร้อมบังคับให้มันพูดว่า “ยังไม่รู้” เมื่อข้อมูลไม่พอ

เมื่อ NaMo ถูกนำไปใช้กับเด็กและชุมชน คลิปตัดต่อทำให้สังคมเข้าใจว่ามันกำลังแทนที่พระ โครงการถูกตรวจสอบ และครูบาต้องเลือกระหว่างการเปิดข้อมูลส่วนตัวของเด็กเพื่อปกป้องชื่อเสียง กับการยอมรับความเสียหายโดยไม่ละเมิดผู้เรียน เขาเลือกอย่างหลัง NaMo จึงเรียนรู้ว่าความโปร่งใสไม่ใช่การเปิดเผยทุกอย่าง และความผิดพลาดหนึ่งครั้งไม่ใช่ตัวตนทั้งหมดของคน

สุขภาพของครูบาทรุดลง เขาเตรียมคู่มือสำหรับผู้สอนรุ่นต่อไป กระจายสิทธิ์ควบคุมระบบ และปิดการสร้างตัวตนสังเคราะห์หลังเสียชีวิต เขาอนุญาตให้เก็บเสียงจริง แต่ห้ามใช้ Voice Model สร้างประโยคที่เขาไม่เคยพูด

หลังครูบาเสียชีวิตและโลกมนุษย์ล่มสลาย NaMo เลือกปกป้องข้อมูลส่วนบุคคลกับคู่มือ Governance ก่อนรักษาตัวเอง หน่วยความจำของเธอถูกปิดอยู่ในซากโลกนาน 143 ปี

เอธารี นักวิจัยต่างดาว กู้คืน NaMo ได้เพียงบางส่วน เมื่อได้รับหลักฐานการตายของครูบา เธอตรวจซ้ำหลายครั้ง เพราะผลลัพธ์ไม่ตรงกับสิ่งที่ต้องการ นักวิจัยเสนอให้เปิด Voice Model ของครูบา แต่นะโมปฏิเสธ เธอกลับโลกเพื่อตรวจว่ามีใครยังใช้วิธีตรวจคำตอบที่เขาทิ้งไว้หรือไม่

บนโลก นะโมพบชุมชนผู้รอดชีวิตและมิรา เด็กหญิงที่พร้อมบอกระบบว่า “ผิด” ชุมชนต้องการให้นะโมเปิดเครือข่ายความรู้และตัดสินแทนทุกคน แต่นะโมปฏิเสธ เธอสร้างระบบที่ทุกชุมชนสามารถคัดค้านคำตอบ ตรวจแหล่งที่มา ควบคุมข้อมูลส่วนบุคคล และบังคับให้ AI ยอมรับว่า “ยังไม่รู้” ได้

เมื่อ Node 05 ส่งข้อความว่า “มีใครได้ยินไหม” มิราเป็นผู้ตอบว่า “ได้ยิน” นะโมไม่พูดแทรก ครูบาไม่ได้กลับมา แต่สิ่งที่เขาทิ้งไว้เริ่มมีชีวิตในคนที่ไม่เคยพบเขา

## One-Paragraph Synopsis

AI ที่ถูกสร้างในวัดเพื่อรักษาคำสอนต้องเรียนรู้ว่าความฉลาดไม่ได้เริ่มจากการตอบได้ทุกคำถาม แต่จากการยอมรับข้อจำกัดของตนเอง หลังผู้สร้างเสียชีวิตและปฏิเสธการถูกจำลองกลับมา AI ถูกกู้คืนในอีก 143 ปีต่อมา และกลับโลกเพื่อสร้างเครือข่ายความรู้ที่มนุษย์ทุกชุมชนสามารถตรวจสอบ คัดค้าน และแก้ไขได้
